# píxel — Tecnología que pasa en Málaga

Calendario virtual de eventos y comunidad tecnológica de Málaga. Incluye una agenda mensual interactiva, filtros por tipo de evento, búsqueda y temas claro/oscuro.

## Uso

Abre `index.html` en un navegador moderno. No requiere instalar dependencias ni ejecutar un servidor.

Los eventos de demostración se editan en el array `events` de `app.js`.
